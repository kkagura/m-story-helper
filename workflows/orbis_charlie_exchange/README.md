# 天空之城中士臼齿兑换：单轮流程

本场景按 [Python 流程插件接口](../../docs/workflow-plugin-spec.md) 实现。原 v1.json 已移除，本文保留业务步骤和截图依据；当前已注册 [中士占位插件](../../app/workflows/builtin/charlie_exchange.py)，已增加单帧对话调试识别，尚无插件运行器、异步对话工具或可运行兑换逻辑，未通过真实点击验收。

运行前由用户准备足够材料、背包空位，并使 NPC 处于可交互范围；流程不自动移动到 NPC、不检查库存/空位，也不核对确认页上的材料/数量。选择列表项仍按“僵尸丢失的臼齿 100 个”定位，属于选择目标，不是检查背包。

NPC 名称与按钮/页面关键词由插件参数模型或脚本中的页面常量定义，可按实际 OCR 校准。图 4 的当前可见列表中没有最终材料，滚动中间帧未提供：插件参数 max_scrolls=12、工具 scroll_steps=3 的向下滚动只是有界开发初值，并非实测操作次数或路径。找不到、无进展、歧义或页面异常均暂停。共 6 个业务步骤，所有工具共享步骤/运行时限和动作预算；不自动重试兑换，不自动重开下一轮。

奖励截图显示 20 个万能疗伤药，作为图片理解的记录；插件按用户约定以明确兑换成功提示为依据，不另外比较奖励数量、背包空间或材料库存。只有看到成功后再关闭对话，才把该轮记为完成；不能只凭确认点击或对话框偶然关闭就宣告完成。

图片对应关系仅用于开发审查，不能用固定样本代替实时交互反馈。已声明插件元数据：id=orbis_charlie_exchange、api_version=1、version=1.3.0、task_id=npc_material_exchange、category=quest；业务参数已在 CharlieExchangeParams 实现，见接口文档。需要 npc_detection/dialogue_ocr/dialogue_scroll/bounded_input，允许 mouse_click/mouse_scroll，均是待实现能力。返回单轮完成摘要与成功提示/关闭的证据，由任务验证器核验；暂停后不按步骤名自动续跑。

当前已编写 SDK、参数/注册表/上下文和仍禁用的执行占位，新增只读判断；单元测试待宿主机运行；真实 OCR、滚动、按钮定位和交互闭环尚未验证。


2026-10-28 识别测试已改为通用入口：默认仅基础信息，选择中士流程后才调用 evaluate/decide_exchange 与按需对话感知。右侧“流程信息”通用展示阶段、参数目标/可见身份、正文、意图和缺失条件；预期 1.png 无对话面板时继续读取场景 NPC 标签，唯一高分匹配则进入等待交互阶段；2–6 为介绍/交易/材料/确认/成功提示。4–6 无 NPC 标签时明确未知，没有可信历史，不得自动填写身份。图4目标不可见时只预览查找；图6成功提示仍缺关闭验证。真实 OCR/浏览器效果待宿主机确认。

当前插件内容版本1.3.0。场景判断集中在 app/workflows/builtin/charlie_decision.py，通用工具不包含中士页面关键词；NPC/材料/数量取参数。未来运行脚本应复用相同单步判断，但运行器和输入仍未实现，当前不执行 run 或任何点击。

初始场景只定位名字标签，不用固定偏移伪造NPC身体框；意图仅预览，点击区域和距离仍需后续识别与验证。
